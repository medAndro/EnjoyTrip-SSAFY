## 실행 방법

현재는 프로젝트 초기 상태입니다. 진입 HTML 파일을 작성한 뒤 아래 방법으로 실행할 수 있습니다.

1. 저장소를 내려받고 프로젝트 폴더를 엽니다.
2. VS Code의 Live Server 등 정적 파일 서버로 `index.html`을 엽니다.
3. 브라우저에서 페이지를 확인합니다.

별도의 프레임워크나 빌드 과정은 사용하지 않습니다.
